## Technical scope

- No analytics, advertising, fingerprinting, telemetry, accounts or file-upload service added.
- `tlcp_storage`: versioned preference choice + expiry, written only on an explicit choice, valid for 180 days. No user ID or tracking ID.
- `tlcp_config`: guarded reads/writes; no access without a current affirmative preference choice. Refusal/withdrawal removes this key. Legacy preferences are not silently used.
- `tlcp_vault`: remains independent, saved on user request. Declining optional preferences does not erase tracks. Bulk deletion has a separate confirmation.
- Same-origin storage is shared with other pages at the same origin. These controls never call `localStorage.clear()`.
- Website policies have no remote embeds, fonts or tracking resources. Email/issue submission is voluntary and leaves the website.
- The deployment workflow stages the policy page and versions its assets alongside the editor.

## Accessibility scope

Labelled controls, decorative icon semantics, visible focus, tab/menu navigation, modal focus containment/restoration and dismissal, reduced motion, a keyboard-resizable elevation panel, and a form-based track-point editor are included. Full nonvisual canvas/terrain/elevation/isometric equivalents, all decoration/rotation/scaling alternatives, all theme/accent contrast combinations and manual screen-reader testing remain incomplete. Do not advertise full WCAG conformance.
